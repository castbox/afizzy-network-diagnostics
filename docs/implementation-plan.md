# 当前实现范围

项目为纯前端静态网络检测页。打开后自动检查 Afizzy 官网、Afizzy API、Thebetter API 的 DoH，并加载一张用户指定的 Afizzy 公开图片；一页展示四组结果，支持停止、重测和本地 JSON 下载。

目标目录仅允许上述三个生产域名与该图片，浏览器只请求两个已审核 DoH 端点和图片 URL。图片加载结果只说明资源在本次浏览器请求中是否完成及耗时；资源较小且跨域传输字节不可读时不输出下载速率。HTTP 业务探测、普通系统 DNS、目标选择器、运行时服务器与桌面探针均已移除。DoH 结果不能替代设备系统 DNS 或业务连通性结论。

正式验收按[部署清单](deployment.md)进行；静态构建与本机浏览器测试不代表真实设备或公网已验证。
